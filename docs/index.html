Every solo note lands in key.

Guitar Scale Tune is a VST3 plugin that listens to your guitar, finds the note you played, and nudges it to the nearest note of the scale you pick. Slightly flat bend, sloppy fret, drifting vibrato: it plays in tune.

Drag the slider as if you were bending a string. The ringed note is where the plugin sends it.

What it does

Snaps to your scale
Choose a key and scale. Notes outside it are pulled to the closest one that belongs.
Retune speed
0 ms is the hard robotic snap. Raise it to keep slides and bends natural.
Amount and mix
Correct fully or only partly, and blend with the original tone.
Built for single notes
Leads and solos. Quiet noise and pick scratches pass through untouched.

Scales included

    Build it with GitHub Actions

    1. Create a GitHub repo and push the project files.
    2. Open the Actions tab. The workflow builds Windows, macOS and Linux automatically.
    3. Download the .vst3 from the run's Artifacts.
    4. Tag a version like v1.0.0 and it publishes a Release with all three downloads.

    Latency is about 15 ms; DAWs compensate for it when mixing. For live monitoring, use the Standalone build with a low-latency audio interface.
